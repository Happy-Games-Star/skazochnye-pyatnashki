# skazochnye-pyatnashki
Сказочные пятнашки 🦄  Игра-головоломка для детей по принципу «пятнашек». Вместо цифр на плитках стоят герои русских народных сказок «Репка», «Теремок» и «Колобок». Нужно расставить их в том порядке, в котором они появляются в сказке. Игра сделана для семейного канала Monica Ro на YouTube.
