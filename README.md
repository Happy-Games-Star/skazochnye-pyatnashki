Сказочные пятнашки 🦄

Игра-головоломка для детей по принципу «пятнашек». Вместо цифр на плитках стоят герои русских народных сказок «Репка», «Теремок» и «Колобок». Нужно расставить их в том порядке, в котором они появляются в сказке. Игра сделана для семейного канала Monica Ro на YouTube.

▶ Играть онлайн

In short (English): a kids' sliding-puzzle (3×3) where tiles are fairy-tale characters, ordered as they appear in the story. Three Russian folk tales, three difficulty levels, a unicorn helper, and a bonus cartoon from the Monica Ro YouTube channel unlocked after the first win. One HTML file, no dependencies. Interface language: Russian.

О чём игра

Поле 3×3: восемь плиток и одна пустая клетка. Плитки нужно сдвигать, пока герои не встанут по порядку слева направо и сверху вниз. Пустая клетка в конце остаётся внизу справа. Так ребёнок не просто решает головоломку, а собирает сказку и запоминает, кто за кем пришёл.

Порядок героев в сказках
Сказка	Порядок плиток
Репка	Грядка, Репка, Дед, Бабка, Внучка, Жучка, Кошка, Мышка
Теремок	Поле, Теремок, Мышка, Лягушка, Зайчик, Лисичка, Волчок, Медведь
Колобок	Дед, Бабка, Печка, Колобок, Заяц, Волк, Медведь, Лиса

Пояснение: в сказках персонажей по 6–7, а плиток должно быть 8. Поэтому в «Репку» добавлена «Грядка», в «Теремок» «Поле», а в «Колобок» «Печка».

Возможности
3 сказки на выбор, выбирать можно в любой момент (партия начнётся заново)
3 уровня подсказок:
Легко: на плитках номера, сверху показан правильный порядок героев
Средне: сверху показан порядок героев, но без номеров
Сложно: без подсказок, только по памяти
Счётчик ходов и таймер (запускается с первого хода)
Нажатие на плитку сдвигает её. Если плитка стоит в одном ряду с пустой клеткой, сдвигается весь ряд
Плитка на своём месте подсвечивается золотой рамкой (в режимах «Легко» и «Средне»)
Единорог-помощник с подсказками и похвалой
При победе герои по очереди «подпрыгивают», как будто тянут репку, и появляется текст из сказки
Бонус-мультик с канала Monica Ro открывается после первой победы
Всегда решаемое перемешивание, адаптация под телефон, героев рисует код (SVG), картинки не нужны
Как запустить
Просто открыть

Скачайте index.html и откройте его в любом современном браузере. Установка не нужна.

Пояснение: игра работает и так, но видео-бонус при запуске файла с компьютера может не показываться (подробности ниже). Для полной работы выложите игру на GitHub Pages.

Выложить в интернет (GitHub Pages)
Создайте на GitHub публичный репозиторий, например skazka-repka.
Нажмите Add file → Upload files и загрузите игру. Файл должен называться именно index.html.
Откройте Settings → Pages.
В разделе Source выберите Deploy from a branch, затем ветку main и папку / (root), нажмите Save.
Через 1–2 минуты игра будет доступна по адресу https://ВАШ-ЛОГИН.github.io/skazka-repka/.

Чтобы обновить игру, снова нажмите Add file → Upload files, загрузите новый index.html и подтвердите замену.

Реклама канала в игре

Игра задумана как подарок от канала. Поэтому в ней несколько мест, где ребёнок и родители видят канал:

Логотип в шапке: по нажатию открывается канал в новой вкладке
Единорог: каждую третью партию он говорит, что игру сделали на канале Monica Ro
Экран победы: кнопка «▶ Смотреть канал Monica Ro»
Блок внизу страницы: «Понравилась игра?» с кнопкой «▶ Смотреть на YouTube»
Бонус-мультик: награда за первую победу

Во время партии ничего не всплывает и не мешает играть. Все ссылки открываются в новой вкладке, игра остаётся открытой.

Бонус-мультик: как он работает
Пока ни одна сказка не собрана, под выбором сказки написано, что бонус закрыт.
После первой победы бонус открывается. Это запоминается в браузере (localStorage, ключ monica-bonus), поэтому при следующем заходе он остаётся открытым.
По кнопке «🎁 Бонус» видео запускается внутри игрового поля. Если нажать кнопку в середине партии, таймер встанет на паузу и продолжится после «← Назад».
Видео подключается через YouTube IFrame API и загружается только по нажатию, поэтому до этого страница с YouTube ничего не тянет.
Если YouTube не пускает встроенное видео, вместо ошибки появляется картинка-превью с кнопкой «▶ Смотреть на YouTube». Видео откроется в новой вкладке.
Если видео пишет «Это содержимое заблокировано» (или похожую ошибку)

Эту ошибку показывает сам YouTube. Обычно причин две:

Файл открыт с компьютера. Встроенное видео не показывается на странице без адреса сайта. Откройте игру по ссылке GitHub Pages.
Для видео выключено встраивание. В YouTube Studio откройте Контент, выберите видео, нажмите Показать больше и включите «Разрешить встраивание».
Как изменить игру

Весь код находится в одном файле index.html. Откройте его в любом текстовом редакторе.

Что изменить	Где искать
Видео-бонус	В скрипте найдите var VID = '...' и замените на ID вашего видео (часть ссылки после v= или после youtu.be/)
Ссылка на канал	Найдите youtube.com/@monicaro (встречается несколько раз) и замените на свой адрес
Реплики единорога	В скрипте в функциях newGame(), win() и в списках фраз
Цвета	В начале блока <style> переменные --red, --gold, --cream и другие
Тексты сказок и подписи	Массив TALES в скрипте
Логотип	Тег <img> в шапке. Картинка записана прямо в файл (data:image/png;base64,...). Чтобы заменить, конвертируйте свою картинку в base64 или подключите обычный файл logo.png
Как добавить новую сказку
Нарисуйте героев. В блоке <svg> в начале страницы каждый герой это <symbol id="cN" viewBox="0 0 100 100">. Добавьте новые с уникальными номерами (последний сейчас c17, единорог c8).
Добавьте сказку в TALES:
n: название
sub: подпись под заголовком
intro: начало фразы единорога («грядка, репка, дед…»)
ic: 8 номеров рисунков по порядку, например [9, 10, 7, 11, 12, 13, 14, 15]
nm: 8 подписей
bg: 8 цветов фона плиток
wh и wp: заголовок и текст на экране победы
Добавьте кнопку выбора. Продублируйте строку <div class="tl" data-k="2">…</div> с новым data-k (3, 4, …).
Технические детали
Что внутри: HTML5, CSS3 и чистый JavaScript. Библиотеки и сборка не нужны.
Решаемость: не любая случайная расстановка пятнашек решаема, ровно половина нет. Поэтому игра берёт собранное поле и делает 150 случайных допустимых ходов, никогда не отменяя предыдущий. Любое такое положение можно собрать обратно. Если по случайности поле оказалось собранным, перемешивание повторяется.
Рисунки: все герои и единорог нарисованы векторной графикой (SVG) прямо в коде.
Шрифт: Ruslan Display из Google Fonts. Без интернета подставится обычный шрифт с засечками.
Звук: в игре его нет.
Хранение данных: в браузере запоминается только факт, что бонус открыт.
Доступность: плитки можно выбирать с клавиатуры (Tab и Enter), у анимации учтён режим prefers-reduced-motion.
Если что-то не работает
Проблема	Что делать
Ошибка 404 после включения Pages	Подождите несколько минут. Проверьте, что файл называется index.html и лежит в корне репозитория, а не в папке
Игра не обновилась после загрузки	Нажмите в браузере Ctrl+F5 (на телефоне откройте страницу в режиме инкогнито)
Нет красивого шрифта	Нужен интернет. Игра при этом работает, просто шрифт запасной
Видео не запускается	Смотрите раздел про бонус выше
Бонус всё ещё закрыт после победы	Браузер, возможно, запрещает localStorage (например, режим приватного просмотра). Бонус откроется после победы, но не запомнится
